# Security policy

## Reporting a vulnerability

Please report security issues **privately** through [GitHub's private vulnerability reporting](https://github.com/dimah-kz/dimah-starter/security/advisories/new) — not in a public issue or pull request.

Include what is affected, how to reproduce it, and the impact you expect. You will get a reply as soon as possible, and credit in the fix unless you prefer otherwise.

## Scope

This policy covers the code in this repository. Vulnerabilities in a dependency (Next.js, Better Auth, Drizzle, dimah-s3 and others) belong with that project; tell us too if the starter's configuration makes them exploitable.

## Supported versions

Fixes land on the `main` branch. Projects created from the template should apply them by hand — see the commit history for what changed.
