# UI

Read when you build or style components, or add a shadcn / ReUI primitive.

## Where components come from

| Kind                 | Where                                             | Edit                                                                          |
| -------------------- | ------------------------------------------------- | ----------------------------------------------------------------------------- |
| shadcn/ui on Base UI | `packages/ui/src/components/*.tsx`                | Generated by `pnpm ui:sync`; hand edits are lost on the next sync             |
| ReUI                 | `packages/ui/src/components/reui/`                | Generated; lasting changes go in `packages/ui/scripts/reui/patches/index.mjs` |
| Dimah                | `packages/ui/src/components/dimah/`               | First-party: edit in place                                                    |
| App components       | `apps/web/src/components/`, segment `components/` | Product UI composed from the primitives                                       |

Import primitives as `@repo/ui/components/<name>` (also `…/reui/<name>`, `…/dimah/<name>`), hooks as `@repo/ui/hooks/<name>`, styles once as `@repo/ui/globals.css`. Icons come from `lucide-react`.

Add a primitive from the repository root:

```bash
pnpm dlx shadcn@latest add <name> -c packages/ui
pnpm dlx shadcn@latest add @reui/<name> -c packages/ui   # then list it in packages/ui/scripts/reui/components.mjs
```

The style is `base-mira` on Base UI, not Radix: props such as `render` replace Radix's `asChild`. A link styled as a button is `<Button render={<Link href={…} />} nativeButton={false}>`.

## Styling

- **Tailwind CSS 4.** Configuration lives in `packages/ui/src/styles/globals.css`: theme tokens, and `@source` lines for every folder that renders classes. There is no `tailwind.config.js`. A new package that renders classes needs its own `@source` line.
- **`cn`** comes from the `cn` package: `import { cn } from "cn"`. There is no `lib/utils`.
- **Logical properties only:** `ms-*` / `me-*`, `ps-*` / `pe-*`, `start-*` / `end-*`, `text-start`, `border-s`. The app also runs right-to-left (`fa`). Set direction on `<html>` alone — [i18n.md](./i18n.md).
- **Prefer `variant` and `size` props.** Add `className` only for what that call site needs; don't restate the radius, padding or colors the primitive already sets.
- **Colors come from theme tokens** (`bg-muted`, `text-muted-foreground`, `border-border`), so dark mode works. Dark mode is `next-themes` with a `class` on `<html>`.
- **Copy comes from `@repo/i18n`**, including `aria-label`s.

## Feedback and forms

- **Toasts:** `toast.add({ title, type })` from `@repo/ui/components/toast`.
- **Fields:** use `Field`, `FieldLabel` and `FieldGroup` from `@repo/ui/components/field`.
- **Pending submits:** `apps/web/src/components/form/form-submit-button.tsx`.
- **Edit forms:** `apps/web/src/components/form/responsive-form-overlay.tsx` is a side sheet, full width on phones. It closes itself when Cache Components hides the route.
